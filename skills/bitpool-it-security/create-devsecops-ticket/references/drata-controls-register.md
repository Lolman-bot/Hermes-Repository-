## What "Monitoring Test" means

* **Monitoring Test** — Drata's `isMonitored` flag. `Yes` means the control has at least one active automated or custom monitoring test (Drata-built, custom, or external) wired to it. `No` means the control is evidenced manually (policy, ticket, uploaded evidence) with no live automated check.
* **Link** — built from the control's numeric Drata ID: `https://app.drata.com/compliance/control-details/<id>/overview`. Clicking a DCF code opens that control directly in Drata.
